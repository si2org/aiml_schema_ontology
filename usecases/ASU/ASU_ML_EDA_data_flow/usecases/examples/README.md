# **SPARQL_query_examples**

## **Overview**
The `SPARQL_query_examples.py` script demonstrates how to perform **data manipulation** using **SPARQL queries** on an RDF graph.

This file provides various SPARQL queries that can be run on an RDF graph, which contains data related to a circuit design, and allows users to manipulate and query the data efficiently. 
The examples included focus on basic querying operations such as **filtering**, **aggregating**, and **selecting specific properties** from the RDF data.

## **Usage**

### **Run the Script**

To run this script, you'll need to specify the **example number** you want to execute via the command line. The example number corresponds to one of the available query examples in the script (1-4).

**Example Usage**:

```bash
python SPARQL_query_examples.py 1    # Run Example 1
